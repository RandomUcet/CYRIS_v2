# CYRIS v2.4.22 — cumulative operational update (in development)

- Modular C wordmark: remove overlap with YRIS; 4.83 vector-unit optical separation, expanded viewBox, consistent header and login dimensions and revised external asset cache key. Compact icon and CYLAB identity unchanged. Static geometry regression; visual browser acceptance pending.
- Shared tables persist pagination resets on filter/sort/scope changes and clamp page when result count shrinks. Nested interactive controls no longer activate the containing row on click or keyboard input. Functional page-state tests included.
- User management explicitly unavailable during participant preview rather than showing an endless loading state; API authorization unchanged.
- JSOC cancels obsolete list requests, clamps invalid pages and validates integer generation input. Authorized synthetic log details can be copied as a clearly marked simulation reference including exercise ID, record ID, UTC timestamp, addresses and message. Clipboard failures are reported. This does not create evidence, send messages, or connect to live telemetry. Functional reference tests included.
- No database migration, new dependencies or release gate bypass. CI, image builds, and production browser acceptance remain required.

## Operational workflow pass
- EXCON prioritizes actionable alerts immediately below key metrics; failed broadcasts, unread urgent messages and real operational holds appear before routine controls. Snapshot freshness distinguishes stale data, paused refresh and current data; active memberships are explicitly not online presence. Requests abort on scope/identity changes; response event checked.
- Legal request inbox cancels outdated requests and clears previously authorized records on load failure; visible error/retry replaces misleading empty results. No access-control or court procedure changes.

## EXCON scenario timeline

Real snapshot time is displayed separately from scenario time, with pause/mode/speed and explicit stale-state labeling. No fake ticking clock or automatic phase actions. PostgreSQL fixture verifies frozen time, real-time fallback, phase order and cross-event isolation.
