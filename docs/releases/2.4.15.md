# CYRIS v2.4.15 — EXCON templates & Spark fast default

## EXCON quick messages
- Ten operational templates in Czech and English: briefing, SITREP, situation change, urgent instruction, phase start, scenario inject, team check-in, service disruption, service restoration and debriefing.
- Four core templates remain visible, six additional templates are available in a compact, accessible disclosure.
- Sending still requires an authorized organizer, selected exercise and recipients, recipient-count recheck, explicit confirmation and idempotent delivery.
- All template bodies contain explicit placeholders; the existing guard blocks sending them unfilled but still allows saving drafts.
- No new notification recipient, data exposure or autonomous delivery logic.

## Spark scenario dataset generation
- When a client omits the strategy, the server now defaults to FAST rather than accidentally choosing slow DETAILED mode. This matches the existing UI default.
- FAST already uses one 45-second bounded AI blueprint request followed by deterministic local generation of linked records.
- DETAILED remains an explicit option, with 75-second maximum provider time per page. Previously saved draft strategies remain unchanged.
- No schema migrations or automatic overwrites of drafts.
