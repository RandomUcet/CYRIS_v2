# CYRIS v2.4.15 — Participant roster and access workspace

- Adds Czech accent-insensitive multi-word participant search, team and no-team filters, separate inactive membership and unavailable account filters, reset controls and roster totals.
- Prevents displaying the previous exercise's roster during a switch or refresh; validates membership event IDs and binds preview requests to the selected membership.
- Serializes local participant mutations, prevents stale action results from updating a different exercise, and handles failed command role lookup. Closed/archived exercises no longer offer command-role changes in this UI.
- Adds focused filter/count tests and source-level scope regression assertions. Server authorization and existing View As restrictions remain unchanged. No migrations.

## Release gate
Exact-head CI, encrypted backup recovery, successful official multiarch release of the previous version and all release assets/digests must be verified before publishing or deploying. Multi-role browser acceptance remains separate.
