# CYRIS v2.4.16 — Spark draft progress and recovery

- Shows saved-record percentage and elapsed time for the current generation attempt, including the initial request. Fast mode explains why progress changes atomically; no invented ETA.
- Supports pausing before the first generation page and stops on non-advancing or mismatched draft responses instead of looping indefinitely.
- Restores the original Spark strategy when reopening a draft; isolates workspace state by exercise, ignores stale history responses, serializes local operations, and separates history retrieval failures from generation messages.
- Adds history search/status filters, draft progress in history, refresh and responsive styling. Clears stale inspectors after cleanup.
- Adds regression tests for progress bounds and advance validation. No provider prompt/model changes, migration, or claimed DGX speedup.

Release only after exact-head CI, isolated encrypted restore and the preceding official release are verified. Real DGX and browser acceptance remain separate.
