# CYRIS v2.4.14 — After-action report exports

## Administrator reporting
- Adds **Souhrn CSV** to the existing after-action report, next to JSON and daily activity CSV.
- Includes event identification, the report snapshot timestamp, membership and operational/audit totals, counts of resources, court cases, legal requests, medical case statuses, tasks, support requests and audit categories/outcomes.
- Keeps **aggregate-only** values and does not include patient details, identities, evidence text or individual case records.
- Uses UTF-8 BOM and CRLF line endings for Czech spreadsheet compatibility; every value is quoted and spreadsheet formula prefixes are neutralized.
- Category rows sort consistently; missing outcome counts display 0. Existing daily activity CSV and print layout remain available.
- Adds focused Node regression tests for fields, empty inventories, number validity and CSV injection.
- No new API endpoints, data migrations, recipient notifications or destructive actions.

## Release gate
- Merge only after exact-head GitHub Actions succeeds: build, typecheck, regression tests, deployment scripts and isolated encrypted backup restore.
- Publish and verify all three Docker image digests (linux/amd64 + linux/arm64) and official GitHub Release assets before updating Ubuntu.
