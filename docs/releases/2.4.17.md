# CYRIS v2.4.17 — Spark inference admission and planning

- Enforces a server-derived per-draft Redis admission scope across API replicas and administrators, in addition to existing user and global limits. Overlapping model requests for the same draft are rejected; other drafts can still proceed within available capacity. Leases expire and are released on failure.
- A completed FAST draft cannot accidentally invoke Spark again, even if the caller supplies the final prepared count. Existing database compare-and-swap is unchanged.
- Shows the planned number of model requests before starting FAST or DETAILED generation (without retries), not an invented ETA. The small dataset needs 1 FAST request or 12 DETAILED requests.
- Adds isolated Redis concurrency tests and database regression assertions, and functional request-plan tests. No database migration, model tuning or hardware benchmark.

Keep stacked on v2.4.16 until its official release is verified, then retarget main and rerun exact-head CI before publication.
