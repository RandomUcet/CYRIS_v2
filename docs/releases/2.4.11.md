# CYRIS v2.4.11 — Unified EXCON Control Center

## New organizer dashboard

A new responsive **EXCON** page at `/events/:eventId/excon` brings existing exercise information into one operator workspace:
- Exercise lifecycle, DEFCON level, active scenario phase and completed phases.
- Real counts of scenario injects (ready, blocked, scheduled, released, drafts) and a linked shortlist of pending injects.
- Draft, scheduled, sent, and failed broadcast counts, upcoming UTC-scheduled deliveries and the latest delivery/read receipt ratios.
- Active participants and non-archived teams, briefings read/acknowledged, unread urgent EXCON broadcasts.
- Active event-wide operational holds, attention indicators for failed messages, waiting injects and unread urgent receipts.
- Shortcuts to Scenario Run Sheet, command/DEFCON, broadcast composer, Spark scenario data, support and after-action evaluation.

A single **event-scoped backend endpoint** aggregates all counters from canonical PostgreSQL records. Only users with server-verified `scenario.manage` permission can access the endpoint; normal participants and cross-event organizers cannot inspect future inject titles. UI visibility also respects view-as restrictions. No fabricated counters, no raw participant identities or private medical records.

The dashboard polls about once every 20 seconds while the page is visible, retains last-known data on transient refresh failures and offers a manual refresh. Scenario inject times and real-world broadcast scheduled times are labeled separately to avoid confusion.

## Verification
- Isolated PostgreSQL regression verifies event and membership scopes, active/inactive/disabled accounts, phases, scenario statuses, briefing receipts, planned broadcasts, notification read rates, DEFCON, current holds, and role revocation. Cross-event secret strings must not appear in the response.
- Contract/UI guard and frontend linkage regression included.
- Existing full CI includes build, typecheck and encrypted backup restore smoke test.
- No database migrations and no change to scenario automatic release policies.

## Future refinements
- Role-based operator dashboard layout presets, drill-down team readiness, realtime websocket events and personalizable widgets.
- Keep human confirmation for destructive/event-wide actions and AI-assisted broadcasts.
