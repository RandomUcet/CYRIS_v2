# CYRIS 2.5.0 — Durable intelligence & exercise preparation

## Release scope

This cumulative minor version consolidates operational exercise preparation and reliability. The main changes since 2.4.22:

- Durable organizer AI jobs in PostgreSQL, scoped idempotency, bounded capacity retries, cancellation of queued jobs, fenced result persistence, account revocation checks, private advice history.
- Spark dataset generation continues server-side after the browser closes. FAST strategy uses one constrained AI blueprint followed by deterministic local assembly; DETAILED saves each validated page. Pause, resume, error categorization, claim leases and atomic creation/queueing. Draft publication remains explicit.
- Actual Spark inference diagnostic from platform integration settings, separate from endpoint discovery. Structured response validation and bounded inference calls.
- EXCON Observer history, first real aggregate observation per 15-minute bucket, 72-hour view, comparable adjacent changes, and exact observations retained with advice. No inferred individual activity scores.
- Saved blueprint can supply the Architect brief and dataset brief. Reviewed structured architect actions create draft phases, empty teams, and private injects, including explicit same-event phase assignment and earlier-only prerequisites. Injects require deliberate preparation before release. No automatic recipient selection, participant text, schedule or release is created by Architect.
- EXCON presentation and navigation revisions: compact status, attention rows, simpler singleton navigation and role-scoped workspaces.
- Platform-admin individual local test accounts, generated one-time passwords, explicit existing exercise roles/units, expiry and revocation. Reserved login domain; separate from LDAP/OIDC and shared team preview accounts.
- Event-scoped role assignment and active-unit revocation, permission-aware registry creation and detail actions, session/workspace identity fencing.
- Licence/permit registry with holders, issuers, validity and relationships; registry media and manual licence date evaluation. Automated licence generation and scenario-clock-derived validity are follow-up scope.
- Bulk canonical resource/index outbox registration and dataset cleanup improvements.
