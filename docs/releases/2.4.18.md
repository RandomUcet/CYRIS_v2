# CYRIS v2.4.18 — EXCON communications workspace

- Isolates the full broadcast editor by exercise; audience previews are bound to exercise, kind and target unit. Immediately rechecks recipient counts before sending and requires reconfirmation if changed. Server-side authorization remains authoritative; a count check is not an identity snapshot.
- Prevents sending or scheduling incomplete quick-template placeholders from the full composer; drafts remain savable. Serializes local send/save/cancel actions, confirms replacing unsaved text, and keeps the saved draft available if scheduling fails.
- Adds accent-insensitive search, message type and plan status filters, counts and clear controls.
- Unifies EXCON manual/automatic refresh to avoid overlapping requests and stale responses. Adds live-refresh toggle and visible warning when paused.
- Adds focused tests; no migration or new delivery types. Browser acceptance and exact-head CI required before release.
