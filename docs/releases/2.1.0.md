## GitHub-only build and release path

Source: private `RandomUcet/CYRIS_v2`. The promoted source is exactly this branch
(review/cyris-v2.1.0-stable-candidate) derived from the CI-verified RC.3 and GHCR preflight hardening.
CI builds Node 24 API, worker and web, checks versions, typechecks, migrates an isolated PostgreSQL,
runs regression tests and performs encrypted backup/restore smoke.

**Only after acceptance**, merge the single stable candidate to protected `main`.
The `deploy/VERSION=2.1.0` change triggers the GitHub Release workflow. It builds and
publishes the three multi-platform GHCR images and GitHub Release assets with digest-pinned
manifest. The Ubuntu server remains on its installed version until `sudo cyrisctl update`
is run (or the site's separately configured update process is executed and verified).

## Application changes since v2.0.3

- Streamlined student-first navigation, role-specific My Work, responsive operational surfaces
  and contextual support/service-status pages; permissions remain authoritative in the backend
- Fixed DEFCON sound semantics (sound only on real DEFCON transition), medical record modal layout,
  corrected registry image rights and accurate audit/role displays
- Permission-filtered relationships search and graph links without hand-entered UUIDs
- Scenario-data image management for **published** generated records with file format/size checks
- Isolated synthetic JSOC logs controlled by EXCON and restricted to relevant technical roles
- Reworked notifications: translated controls, contrast, keyboard handling, mobile layout,
  stale fetch protection, safe local navigation and error/retry states
- Read-only View As restrictions preserved and notification center hidden while impersonating
- Build version displayed in the navigation footer
- CI checks translation keys and stable build identity
- `cyrisctl github verify` checks private GitHub Releases + the three digest-pinned GHCR images before outage
- A failed new GitHub/GHCR credential check does not overwrite the previously stored token/root Docker auth
