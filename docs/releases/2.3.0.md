# CYRIS v2.3.0 — Legal collaboration and after-action reports

**Candidate documentation — release is gated on exact-head GitHub CI, isolated database/restore tests, and packaging verification.**

## Scope
- Separate prosecutor, judge/judicial panel and expert-liaison event roles, without granting those roles to users automatically.
- Formal court-case evidence, medical, laboratory, forensic, document and expert-opinion requests with team targeting and deadlines.
- Cross-case legal inbox, state transitions, immutable per-response history and audited responses.
- Privacy-safe in-app notifications when an eligible addressed unit receives a legal request, and when the requester receives a response (never email confidential case text).
- Printable court dossiers, medical encounter reports, lab and forensic findings from existing permission-gated API endpoints. Browser print supports Save as PDF.
- Administrator-only after-action aggregate statistics, downloadable JSON and printable report.
- **Read-only** preview of partial versus whole-event deletion impact; neither destructive cleanup mode is enabled.

## Database migrations
- 0028 court requests, guarded event ownership and request revision
- 0029 append-only legal request response history, unique per-request revision

## Important limitations
- **Not an official court filing, electronic delivery or medical record system.** All materials are simulated.
- No web-triggered irreversible purge. Requires verified off-host encrypted backup and safe cross-store cleanup (issue #21).
- No general-purpose complete-event ZIP/PDF export; printable records cover the above listed modules only.
- Full multi-role user acceptance, browser/device tests and security review are still recommended before a production exercise.
- Actual server deployment remains a separate operator-controlled action; a release does not itself upgrade the VM.

## Server update after official release
```sh
sudo cyrisctl self-update
sudo cyrisctl github verify
sudo cyrisctl update --version v2.3.0
sudo cyrisctl status
sudo cyrisctl doctor --full
```
Do not run these instructions before a published official GitHub Release, verified digest-pinned images and an encrypted pre-migration backup.
